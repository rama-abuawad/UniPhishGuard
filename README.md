UniPhishGuard

AI-powered phishing detection system for university email environments.

Features
- Email (.eml) analysis
- Header inspection
- URL analysis
- Attachment inspection
- AI-based phishing detection
- Explainable risk scoring
- Recommended security actions

Tech Stack
- Python
- FastAPI
- Scikit-learn
- BeautifulSoup
- SQLite
- HTML/CSS/JavaScript

Status
Currently under development.
